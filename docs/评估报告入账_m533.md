## 二、量出的事实：xplat→src 依赖闭包（报告 P0-①，F1-0）

工具：第 13 闸 `docs/tools_layer_gate.py` 本刀新增「依赖闭包」段（剥注释后抓 `import com.sdzjz.…`，逐级匹配 src 顶层类）。

| 被引 src 类 | 引用它的 xplat 文件数 | 加载器状态（m532） |
|---|---:|---|
| `Sdzjz` | 2 | 零 Fabric（F1a 拆成 `init()` 静态入口） |
| `block.StructureCoreBlockEntity` | 4 | 零 Fabric |
| `block.StorageCoreBlockEntity` | 4 | **待拆 F1c**（`Storage<ItemVariant>` 提供侧 5 符号） |
| `block.DataPanelBlockEntity` | 4 | 零 Fabric |
| `block.DataCableBlockEntity` | 2 | 零 Fabric |
| `block.TradeCenterBlockEntity` | 2 | 零 Fabric |
| `registry.ModBlockEntities` | 6 | 零 Fabric（F1a 换原版 `BlockEntityType.Builder`） |
| `registry.ModItems` | 7 | 零 Fabric（F1a 换原版 `CreativeModeTab.builder`） |
| `registry.ModScreenHandlers` | 6 | 零 Fabric（F1b 换 `Menus.type`） |

结论：**9 类里 8 类已零加载器符号，1 类在待拆表且正是下一刀**。闸判据：xplat 引到 `SRC_GLUE_OK` 任一文件 → 红；引到 `SRC_GLUE_PENDING` → 报告数字（欠账可见，F1c 收官应归零）。
报告另两条 F1 技术检查点原样入账到 F1d：① `ModBlocks/ModItems` 静态字段初始化即注册 → NeoForge 须在 `RegisterEvent` 内触发类初始化（F1d 行早已列）；② `FabricXfer` 迁 `IItemHandler` 要**双侧**（访问外部容器 + 暴露自家存储），验收补「部分接收 / 失败路径 / 组件保真 / 目标全满 / 源不足 / 端口切换 / 卸载重载 / 双向同时」。
