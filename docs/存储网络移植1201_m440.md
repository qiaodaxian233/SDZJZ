## 二、API 差异清单（核名依据=训练知识+上游地址簿 raw 可复核；【核】=落刀前再翻源码确认）

1. **物品 NBT**：组件三式 → `getTag()/getOrCreateTag()/setTag()`（mojmap 1.20.1 名，非 Yarn 的 getNbt）。
   TagItemData 对位 ItemData 五口：copyOf=`hasTag()?getTag().copy():new`；view=`hasTag()?getTag():共享空表`；
   write=`setTag(n)`；has=`hasTag()`；clear=`setTag(null)`。精确条目身份键从"组件哈希"退"tag 哈希"。
2. **BE 存读**：`saveAdditional(CompoundTag)` / `load(CompoundTag)`——无 HolderLookup.Provider 参；
   `ContainerHelper.saveAllItems(tag, items)` / `loadAllItems(tag, items)` 无注册表参。ItemStack 序列化
   `stack.save(new CompoundTag())` / `ItemStack.of(tag)`（对位 1.21 的 save(lookup)/parse）。【核】
3. **注册**：`new ResourceLocation(ns, path)`（1.21 是静态工厂）；`Registry.register(BuiltInRegistries.X,…)`；
   `FabricBlockEntityTypeBuilder`（Fabric 0.92 在位）。方块/物品 Settings 链式名基本同。【核】
4. **transfer API**：`net.fabricmc.fabric.api.transfer.v1.*` 0.92 同包同形——ItemStorage.SIDED/
   Storage<ItemVariant>/SnapshotParticipant/Transaction 全在（Create Fabric 移植正是消费这套）。
   FabricLedger 与 FabricXfer 的内脏**近乎原样**可用；ItemVariant.of(stack) 1.20.1 走 tag 身份。
5. **tick 注册**：BlockEntityTicker 同形。ServerTickEvents 等生命周期事件 0.92 同包。
