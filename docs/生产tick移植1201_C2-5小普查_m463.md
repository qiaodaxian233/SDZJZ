# 生产 tick 移植 1.20.1：C2-⑤ 小普查与分片稿（m463，零代码笔）

m458 留话兑现：C2-⑤ 动刀前对 SCBE 主战场单独小普查。口径同 m450/m455：先量版图、再对地基、
后定分片；世代差显式记档，不静默漏抄。

## 一、主线版图实测（StructureCoreBlockEntity，1.21.1 主线）

- **tickInner 主循环 155–1611 ≈ 1456 行**：预算复位 → m339 经验池公平层 → 节点逐台 dispatch →
  produced 时 pushOutput → m114 断网喷射（2t）→ 状态灯节流同步。
- **"五分支"实测是 17 个 item 分支**（m450 提法系粗记）：本稿按生产机制归**五族**——
  ①**数据驱动族**：通用 MachineItem 分支（1511–1571，仅 61 行）吃 MachineDef 表驱动，
  覆盖 101 台绝大多数（矿机/农场/生成器/工厂类全在此）；CropFarm 单列但同构。
  ②**配方域族**：熔炉族（733）/AutoCrafter（542）/酿造塔（601）/附魔工厂（657）——
  依赖 RecipeAccess 平台口 + 组件产物走精确账本。
  ③**实体交互族**：村民交易（843）/折扣机（1436）/抓物笼刷怪（1572）/sculk（1482）。
  ④**经验经济族**：复制机（918）/虚空处理器（429）/磨石回收（792）——xpPool 消费/生产端。
  ⑤**区块机器线**：扫描（953）/储存（1003）/过滤（1087）/移除（1091）/无限信标（1397）。
- **脊柱辅件**（族外共用，行号=入口）：cyclesThisTick 1685（预算累积+CoreScheduler 四层闸）、
  nodeBufs 73（每节点在途缓存，连线按边路由）、topUpSource 1765 + dualCount/dualWithdraw
  （m340 补足）、supplyFor 2954（供料线）、depositFor 2735（产出定向仓）、resolveInputSource
  （BFS 找仓）、addOutput 3496（8 格输出缓存）、pushOutput/resolveOutTarget/ejectOverflow
  3540+（出货与断网喷射，m461 起含 FTA 分支）。
- **两颗路由脑**：chainWants 2807（链需求递归，m218d visited 复用）、distribute 3199 +
  distributeEven 3159（出线两轮垫底/均分，m355 数组化）——生产 tick 里最重的图算法，
  只被"机器↔机器连线"语义消费。

## 二、1.20.1 地基对表（C2-①~④ 已建成什么）

- **白捡（common 直挂）**：Machines 101 台 MachineDef 唯一数据源、MachineXp、CoreScheduler
  （判官已在主线验过公平性）、SdzjzConfig。
- **白名单可挂（xplat 子集，m451 机制）**：DropRolls（依赖仅 RandomSource+MachineDef，闭包干净）；
  StorageAccess 接口（依赖仅 ItemStack）——挂上后 StorageCore120 补 implements 即与主线辅件同型。
- **不可挂记档（m450 发现②）**：NodeTags/NodeUpgrades 摸 ModItems 注册链——1.20.1 侧
  runningCount/machineFilterAllows 等到序**参数化重写**（首片恒 running=1、无过滤，升级体系世代差）。
- **已有骨架**：CanvasGraphState120 全表在位——machineNodes/connections/storageEdges
  （m458 循环手势 kind 0=产出 1=供料）/nodeStatus+nodeReason 灯表/busTop 库存榜；
  StorageCore120 双账本（deposit/count/withdraw/精确四口/xpBank）；StructureCore120 仅 101 行
  **无 ticker**——生产 tick 从零接。
- **缺口**：1.20.1 无 RecipeAccess 实现（xplat 只有 LegacyRecipeAccess=1.21.1）→ 配方域族
  前置；无输出缓存/喷射体系；无 nodeBufs。

## 三、世代取舍（显式记档，非漏抄）

- **区块机器线（族⑤）不入 C2**：五台机=独立战役（PersistentState/选区高亮/世界写入），
  1.20.1 首发不带，评论区如问按"世代功能分层"答。
- **实体交互族（族③）后置评估**：交易/抓物笼牵 GUI 与实体 NBT 两摊，逐台议。
- **升级体系（速度/数量/并发）首片不带**：NodeTags 不可挂连坐，恒 1 台恒 1 倍起步，
  参数化重写到序再上。
- **输出缓存+断网喷射首片不带**：产出必须接仓（storageEdges kind0），无仓=红灯
  "未连产出仓"待机——比主线严但零吞件零实体洪水，缓存/喷射随 ⑤c 补。

## 四、分片（每片独立里程碑，判官随片）

- **⑤a 脊柱+数据驱动无输入类**：tick 挂线（ticker 注册+running 闸+CoreScheduler 预算）→
  cyclesThisTick 移植 → 通用分支的 consumesInputs=false 半（生成器类：产出 rollDrops →
  kind0 仓 deposit → 灯表+busTop）。判官：预算折算/无仓红灯/产出入账对数。
- **⑤b 数据驱动耗料类**：consumesInputs=true 半——kind1 供料仓 count 折算周期 → withdraw →
  产出同 ⑤a。判官：料不足按料折算/无供料红灯/进出账恒等式。
- **⑤c 机器↔机器连线语义**：nodeBufs 在途缓存 + distribute 两轮垫底 + chainWants 链需求 +
  输出缓存。体量最大，届时再单独小普查两颗路由脑。
- **⑤d 配方域族**：RetroRecipeAccess（RecipeDomainAssertions 七类判定现成，喂 1.20.1 配方表
  跑同一套断言=跨版本行为不变量白捡）→ 熔炉族 → AutoCrafter → 酿造/附魔（组件产物精确账本）。
- **⑤e 实体交互/经验经济族逐台评估**：复制机/虚空处理器（xpPool 已有 xpBank 口）优先，
  交易/抓物笼评估后议。

## 五、风险记档

- **storageEdges 消费口径以 m458 循环手势为准**（产出=机器出货入该仓，供料=该仓给机器上料），
  ⑤a 动刀首件事=核 CanvasGraphState120 边表元组格式，别按主线 outT/hasIn 惯性写。
- **1.20.1 与主线同用 Mojmap**（StorageCore120 实证 net.minecraft.world.level.Level），但
  1.20.1 无 DataComponents——组件产物（山羊角/附魔书）全走 TagItemData（C2-① 已兑现），
  ⑤d 前别碰组件产物机器。
- CoreScheduler 是全服静态池——1.20.1 与主线**不会同进程**，无串账风险，但判官记得 clearAll
  首尾护栏（主线 m309 同款）。
