# C2-④ 画布屏与节点操作分片方案（m455 小普查，m450 稿规矩兑现）

## 一、蓝本版图（0.1.454 时点实测）

- **StructureCoreScreen 3435 行 104 方法五大区**：主画布渲染（renderBg 533→drawNode 1015→
  renderLabels 1433）/小地图（895）/浮层四件（改名 1731/设置 1804/帮助 1888/右键菜单 2228）/
  交互（mouseClicked 2350-2711 共 360 行、mouseDragged 2715、mouseScrolled 1532）。
- **同步管道**：Legacy=观众定向推送（CanvasSnapshotPayload，flushCanvasSnapshot 每 tick 至多
  1 份/核心 + 200t 自愈重发 m276）。
- **payload 归类**：快照 2（CanvasSnapshot/CanvasEnds）；节点操作 10（Add/Move/Remove/Link/
  Fuse/Group/GroupMove/Pause/Sensor/Switch/Target/Upgrade/Filter 中前四为最小可玩集）；
  存储连线 3（StorageLink/NodeMove/NodeHome）。

## 二、本世代协议定性（同 m447 面板口径）

快照传输走**轮询请求-响应制**（开屏首查+每 20t+每操作后重查）而非观众推送——精简协议一致性
优先，m275/m276 的推送与自愈体系随规模需要再上（记档为世代差非漏抄）。快照体=CanvasGraphState120
的 writeRenderNbt 整包（writeNbt/readNbt），**应用前节点数过界拒绝**（有界红线落在应用层，
1024 硬顶常量）。

## 三、分片排刀

- **④a（m456）画布屏最小可玩（只读）**：StructureCoreMenu120（开屏/stillValid，蓝本 handler
  仅 92 行同构）+快照两包（Query C2S/Snapshot S2C）+CanvasScreen120 第一片：视口（平移/缩放/
  网格）+节点绘制（图标+SciSkinPalette 框+状态灯环）+连线（pose 旋转画真对角线，Axis 1.20.1
  在位）+小地图与浮层四件全数不带。
- **④b（m457）节点四操作**：NodeAdd/Move/Remove/Link 四 C2S（服务端权威落在 m454 四拓扑操作
  上）+屏交互（手持机器点画布放置/左键拖动/右键摘回/连线模式）。
- **④c（m458+）**：存储端点扫描与机器↔存储连线（生产 tick 的前置）；分组/暂停/徽章/浮层到序
  再排。**C2-⑤ 生产 tick 五分支**单独立段（SCBE 主战场，届时再小普查）。
