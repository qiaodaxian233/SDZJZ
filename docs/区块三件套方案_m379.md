# 区块三件套方案（m379 方案稿，m274 先例：先出方案再动手，待作者拍板）

> 范围：区块机器线收官三台——**区块扫描器 / 区块储存器 / 区块复制器**。
> 已交付三台（移除器 m376 / 过滤器 m377 / 虚空处理器 m378）不在本稿范围。
> 本稿含推荐默认值：作者回一句"按推荐来"即可按第四节切分开工；有异议逐条改。

## 一、职责划分

| 机器 | 一句话 | 输入 | 输出 |
|---|---|---|---|
| 区块扫描器 | 读取端：绑定区块→周期扫描→**统计报告** | 世界内右键绑定（移除器同款） | 卡面摘要+悬停完整报告（方块 Top8 / 方块总数 / 矿物合计 / 生物数 / 容器数） |
| 区块储存器 | 模板端：绑定区块→全量扫描→**存成"区块数据核心"物品** | 世界内右键绑定 | 区块数据核心 ×1（引用式，见决策1） |
| 区块复制器 | 重建端：吃数据核心+**照 BOM 收料**→目标区块重建 | 数据核心（画布节点内嵌）+存储网络材料 | 世界内重建的区块 |

招牌全链成型：`扫描器(侦察) → 移除器(拆) → 过滤器(筛) → 虚空(炼) → 储存器(存档) → 复制器(重建)`。

## 二、五项核心决策（推荐+理由，待拍板项标 ★）

### 决策1：模板存哪（最大地雷）——推荐 **引用式 PersistentState**
- ❌ 全量存物品 NBT 组件：一个区块 98304 方块态，调色板压缩后仍几十 KB～数百 KB；
  物品组件随背包**全量同步客户端**、随手复制随存档漂——包体/存档双爆炸，m291 有界精神的反面。
- ✅ 推荐：模板本体存服务端 PersistentState（m296 声明表/m311 仓位账同款刀法，在树双先例；
  全局一张模板库挂主世界，键=UUID）。"区块数据核心"物品 NBT 只存
  `{模板UUID, 原区块坐标+维度, 摘要(方块总数/类型数)}`——物品轻如鸿毛，模板服务端权威。
- 模板内部格式：**调色板+索引**——`NbtHelper.fromBlockState` 存调色板条目（yarn 编译级核到，
  含属性；回读 `toBlockState(lookup, nbt)`），方块位存 short 索引数组；**按 Y 分段（16 段）**，
  全空气段整段跳过（地表区块实存常 <1/3）。粗算石质区块 ~150–300KB NBT，PersistentState 落盘无碍。
- 孤儿核销：数据核心物品被销毁后模板成孤儿——照 m347 渐进核销刀法：模板带 `lastSeen` 时间戳，
  复制器/储存器每次触达即续期，超期（默认 30 天游戏内时长？★倾向不自动删，只出 `/sdzjz` 
  子命令手动清点+删除，服主自治）。**★待拍板：自动核销 or 只给手动清理命令（推荐后者，模板=玩家资产，程序不擅动）。**

### 决策2：方块实体怎么处理——推荐 **不入模板（复制为空气）**
- 箱子存了也是空箱（绝不复制库存——防复制别人基地），刷怪笼方块态无数据=猪刷怪笼，
  **原版不可获取物凭空复制=经济破坏**。与移除器 `chunkRemoverSkipBlockEntities` 默认对称：
  移除跳过它，模板也不认它。
- **★待拍板：A=BE 方块一律不入模板（推荐，复制出来是空气）；B=存方块态清 BE 数据（空箱/猪笼）。**

### 决策3：重建材料账（经济决策）——推荐 **照模板 BOM 收料**
- ❌ 免费重建=无限钻石块，一票否决。
- ✅ 推荐：模板生成时同步落一份 **BOM（方块→物品形态 asItem 计数表，与过滤器同口径）**；
  复制器 chainWants=BOM 余量（供料线/链式拉料全套白捡），**料到多少建多少**——逐层重建，
  收料与放置同拍结算，游标断点续建（移除器游标同款）。无物品形态方块（传送门/火等）不入 BOM
  也不重建（跳过该位）。
- 经验加速/打折（复制机联动）=二期，本期不做。

### 决策4：重建行为——推荐 **自底向上 + 只填空气 + 不强载**
- 复制器手持右键绑定目标区块（移除器同款 useOnBlock）；重建自底向上逐层（与移除自顶向下对称）。
- **只在空气位放置**：目标位已有方块=跳过且**不退料不虚耗**（该位材料根本不收——BOM 余量按
  "还需重建的位"实算）。防 grief/防吞玩家建筑。**★待拍板：要不要加"强制覆盖"档（推荐不加，
  想清场先用移除器，机器组合就是卖点）。**
- 未加载红灯不强载（m142）；仅同维度绑定；`setBlockState(pos, state, 3)`。
- 液体/含水方块：调色板存的是含 waterlogged 属性的完整方块态，照建；纯液体源方块照建
  （水桶/岩浆桶入 BOM？**推荐：纯液体位不入模板**——液体会自己流，省 BOM 桶账）。

### 决策5：扫描器报告面——推荐 **卡面两行 + 悬停完整报告**，数据面板页=二期
- 节点 NBT 存：方块总数/类型数/矿物合计（#c:ores 标签？无标签则内置矿物 id 表）/容器数/
  生物数（`getEntitiesByClass` 在树）+ Top8 方块计数。
- 卡面：行1 `方块 62.3K·类型 41`，行2 `矿 812·柜 6·生物 9`；悬停节点=完整 Top8（画布节点
  已有悬停浮窗机制可挂）。扫描游标预算制（移除器两本账同款），扫完落"报告时间戳"，重扫=菜单
  "重新扫描"或重绑。
- 数据面板新页是大 UI 工程，二期挂待办。

## 三、护栏对表（全部沿用已立规矩，零新原则）
- 扫描/放置预算与游标上限两本账（m376 教训）；游标每拍落盘。
- 模板库封顶 config：`chunkTemplateMaxCount`（全局默认 256 份★）+单模板尺寸上限（异常即拒存出声）。
- 复制器收料走存储网络标准口（chainWants/供料线），绝不直造物品。
- 三台全带 config 开关；configVersion 逐笔 +1。
